# Sistema Préstamos/Anticipo v0.3

Navegación simplificada:
- Nuevo movimiento
- Personal
- Administración

La vista Personal incluye filtros por mes, persona y tipo, total general/filtrado, colores por tipo, generación automática de reporte CSV y detalle por persona.

Ejecutar:
```bash
npm install
npm run dev
```
